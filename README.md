# Ink Tools · 墨水屏工具箱

墨水屏桌面工具：台历 / 时钟 / 番茄钟 / 待办 / 打卡 / 倒数日，一个 Activity、一块 Canvas 画完。

**62 KB · 0 权限 · 0 依赖 · 不联网**。默认只到分钟、只重绘变化的字符，放着不动几乎不耗电。

---

## 功能

| 页面 | 功能 |
| --- | --- |
| **台历**（首页） | 日期星期、置顶倒数日、大时钟（点进全屏）、今日待办与倒数日双栏（点条目直接勾选，超出翻页）、本周打卡格、日常习惯条（点一下即打卡）、番茄状态 |
| **全屏时钟** | 大字时:分、12/24 小时制、点击切换农历 / 电量、字号按屏宽自适应、常亮 |
| **番茄钟** | 工作 5–90 / 短休 1–30 / 长休 5–60 分钟、2–8 轮可调；大字倒计时、线框进度、暂停 / 继续 / 重置 / 跳过、自动进入下一阶段；历史按月筛选与分页，可复制 / 导出 TXT / CSV |
| **待办清单** | 未完成 / 已完成分区计数、勾选即移入下方并加删除线、今天 / 全部范围、逐条改与删、批量录入、全部完成、清除已完成 |
| **日常打卡** | 全部习惯一框装下，第一次点选中、再点才打卡；单习惯整月月历，每习惯固定槽位，实心已打卡 / 空心未打卡，点「补记」可补打或撤销；本月次数、完成率、全勤、最长连续；添加 / 批量添加 / 改名 / 删除 |
| **倒数日** | 事件与日期、还有 / 已过天数、置顶一条到首页、改名称 / 改日期 / 删除、批量录入、清空 |
| **设置** | 显示秒、时间制、农历、常亮、OLED 模式、字号 5 档（1.3–2.3，1.3 为标准）、番茄钟时长、电量统计（点开是明细：每段起止时间 / 电量变化 / 使用中或离开）、导出配置（仅配置 / 含番茄明细）、导入配置（可选是否覆盖番茄记录）、清空数据、墨水屏使用建议 |

界面纯黑白线描，没有实心黑块、反白黑底与动画；局刷 / 清残影交给系统，App 只决定重绘哪一块。

## 构建

需要 JDK 与 Android SDK `platforms;android-34`、`build-tools;34.0.0`，不用 Gradle。

```bash
export ANDROID_HOME=/path/to/android-sdk
./build.sh                    # 产物 eink-toolbox.apk
adb install -r eink-toolbox.apk
```

推送 `main` 或打 `v*` tag 时 GitHub Actions 自动打包，版本号是新的会同时发布 Release。
